HOW TO READ

01
Coverage ≠ Need

จังหวัดที่มีหลาย source หมายถึงตรวจสอบต่อได้มาก ไม่ได้แปลว่าควรได้งบมากกว่า

02
Record ≠ Person

แถว Area-Based คือหน่วยเข้าร่วมโครงการ ส่วน Housing คือ observation ตาม resource

03
Source score

METHODOLOGY

เส้นแบ่งที่ทำให้ข้อมูลสาธารณะยังน่าเชื่อถือ

1
Source first

เริ่มจาก registry และ URL รัฐบาล/มหาวิทยาลัย พร้อมบันทึกเวลาและ hash

2
Public projection

เผยแพร่เฉพาะ aggregate และทะเบียนสาธารณะ ตัด 2 wallet sources ออกจาก cloud

3
Semantic labels

ไม่เรียก candidate ว่า KPI และไม่รวมหน่วยต่างกันเป็นคะแนนนโยบาย

4
Open verification

ทุก visual มี JSON/CSV คู่กัน และมี manifest สำหรับตรวจไฟล์ย้อนหลัง
