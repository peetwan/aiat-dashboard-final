แดชบอร์ด F2: กดแล้วเห็นอะไร

เส้นทางหลักของผู้ใช้ในแดชบอร์ดฝ่าย 2 และสองจุดที่ระบบแสดงผลแบบอื่น คือเมื่อตัวชี้วัดไม่มีข้อมูลรายจังหวัด และเมื่อตัวชี้วัดเป็นยอดรวมที่ไม่มีรายชื่อ

  • ตัวชี้วัดที่ไม่มีข้อมูลรายจังหวัด เช่น K09 และ K10 (แยกตามภาคของ Learning dashboard) หรือผู้ได้รับการประเมินใน C08 (ทั้งประเทศเท่านั้น) ระบบจะกลับไปมุมมองประเทศไทย และแจ้งว่า "ปรับขอบเขตข้อมูลแล้ว"
  • บนการ์ด "—" หมายถึงยังไม่มีตัวเลขที่รองรับสำหรับพื้นที่ที่เลือก ส่วน 0 หมายถึงนับได้ศูนย์ในข้อมูลชุดนี้
  • ตัวชี้วัด จังหวัด ตัวกรอง หน้า และรายละเอียดที่เปิดอยู่ ถูกเก็บใน URL จึงส่งลิงก์ให้ผู้อื่นเปิดหน้าเดียวกันได้
  • แท็บ รายการ เปิดได้จากภาพรวมทั้งประเทศด้วย ไม่จำเป็นต้องเลือกจังหวัดก่อน
  • แท็บ ที่มาและข้อจำกัด เปิดได้ทุกเมื่อ ไม่จำเป็นต้องผ่านขั้นยอดรวม · ที่มา: app/static/f2.js
