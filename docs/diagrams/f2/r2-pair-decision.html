คู่ระเบียนหนึ่งคู่ถูกตัดสินอย่างไร

ทุกชนิดข้อมูล (นวัตกรรม ธุรกิจ สินค้า บุคคล ข้อมูลวัฒนธรรม กิจกรรม) ตัดสินคู่ระเบียนตามลำดับเดียวกัน การตัดสินของคนมาก่อน ตามด้วยกฎ แล้วจึง LLM ซึ่งใช้เฉพาะนวัตกรรมและสินค้า และทำได้เพียงแยก ไม่เคยรวม

  • ระเบียนถูกรวมทีละคู่ คู่ที่จะทำให้ระเบียนซึ่งต้องแยกกันมาอยู่กลุ่มเดียวกันจะไม่ถูกรวม (การตัดสินที่ขัดกันถูกรายงานในตาราง decision_issues)
  • คู่ที่รอตรวจแต่ผลของคู่อื่นตัดสินได้แล้ว เช่น อยู่กลุ่มเดียวกันแล้ว หรือต้องแยกตามคู่อื่น จะไม่ต้องตรวจ (ระบุว่า transitive)
  • "ไม่แน่ใจ" คือคนตรวจแล้วแต่หลักฐานไม่พอ ระเบียนจึงแยกกันและจะไม่ถูกถามอีก
  • การแยกสินค้าอัตโนมัติด้วย LLM อยู่ในโค้ดชุดใหม่ (branch feature/f2-offering-judge-auto) ซึ่งรอรวมเข้า main ก่อนหน้านั้นใช้กับนวัตกรรมเท่านั้น
  • คำตอบของ LLM ที่ไม่ใช้อัตโนมัติ แสดงเป็นข้อเสนอในหน้าตรวจ · ที่มา: tools/f2/resolve/__init__.py และ resolve/judge.py
