Architecture · F2

F2 ตั้งแต่เว็บไซต์ต้นทางถึงแดชบอร์ด

ข้อมูลไหลจากซ้ายไปขวา ข้อมูลที่มีชื่อบุคคลไม่ขึ้น repo สาธารณะ: ข้อมูลดิบ (snapshot ที่เก็บจากเว็บไซต์) อยู่ใน R2 ของทีมและในเครื่อง ส่วนไฟล์การตัดสินและหน้าตรวจอยู่ในเครื่องของผู้ดูแลเท่านั้น สิ่งที่ข้ามไปฝั่งสาธารณะต้องผ่านชุดรอเผยแพร่ (release candidate) ซึ่งตรวจฟิลด์และความเป็นส่วนตัว และเจ้าของข้อมูลต้องอนุมัติก่อน

  • ดึง snapshot ด้วย python tools/evidence_pull.py <source_id> · รันไปป์ไลน์ด้วย python -m tools.f2 clean / resolve / measure / publish
  • LLM judge ทำงานเฉพาะเมื่อสั่ง python -m tools.f2 judge --send ส่งเฉพาะคู่นวัตกรรมและสินค้าที่รอตรวจ ปิดชื่อและข้อมูลติดต่อก่อนส่ง ผู้ให้บริการตั้งไว้ไม่เก็บข้อมูล
  • แดชบอร์ดอ่านเฉพาะไฟล์ใน data/public/f2 ที่เผยแพร่แล้ว ไม่คำนวณใหม่ตอนเปิดหน้า
  • รายละเอียดแต่ละขั้น: docs/f2.md (The pipeline, Publishing, API and dashboard)
