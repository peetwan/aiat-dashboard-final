ELI5 GLOSSARY

คำศัพท์ที่ต้องรู้

Grain

หนึ่งแถวแทนอะไร เช่น ผู้เข้าร่วมหนึ่งราย โครงการหนึ่งโครงการ หรือ GIS feature หนึ่งชิ้น

Candidate

ข้อมูลที่ใช้ทดสอบ/แสดงพร้อมคำเตือนได้ แต่ความหมายยังไม่ได้รับรองเป็น KPI

Artifact

ชุด JSON ที่ปรุงและตรวจเสร็จแล้ว พร้อมให้ API และ Dashboard อ่าน

Endpoint

ประตู API หรือ URL ที่ระบบใช้ขอข้อมูลจากเว็บไซต์ต้นทาง

Provenance

สูติบัตรของข้อมูล บอกว่ามาจาก source, endpoint, รอบดึง และหลักฐานใด

Snapshot

ภาพถ่ายข้อมูล ณ ช่วงเวลาหนึ่ง ใช้เมื่อไม่ควรหรือไม่สามารถดึง API สดได้ตลอด
